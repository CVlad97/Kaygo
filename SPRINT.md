# Sprint pilote KayGo

## Objectif
Mettre KayGo en pilote prudent et credible pour petits colis France Martinique.

## Actions prioritaires

1. Verifier le build monorepo.
2. Garder le front public utilisable meme si l API est indisponible.
3. Renforcer les mentions phase pilote et validation humaine.
4. Ajouter formulaire expediteur.
5. Ajouter formulaire voyageur.
6. Rendre les objets interdits tres visibles.
7. Ajouter WhatsApp pre-rempli pour demande colis et voyageur.
8. Connecter les demandes au flux Irchestrator.

## Regles

- Ne pas promettre transport automatique.
- Ne pas promettre livraison garantie.
- Refuser tout colis douteux ou non controlable.
- Valider manuellement chaque matching.
